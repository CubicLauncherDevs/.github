## ¿Qué es CubicLauncher?

CubicLauncher es un launcher alternativo de Minecraft enfocado en rendimiento, simplicidad y accesibilidad.

Está diseñado para ser ligero, rápido y fácil de usar, incluso en equipos de bajos recursos.

## Características

- Interfaz simple y fácil de usar  
- Buen rendimiento en PC de gama baja  
- Compatible con múltiples versiones de Minecraft  
- Soporte para diferentes métodos de inicio de sesión  
- Proyecto de código abierto
